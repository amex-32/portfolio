# Portfolio

Mon portfolio : présentation, projets réalisés pendant ma formation et contact.

Site statique en HTML et CSS, sans build. Pour le voir en local, ouvrir `index.html` ou lancer `python3 -m http.server`.

- `index.html`, `style.css` : la page principale
- `projects/` : une page par projet
- `api/leaderboard.js` : petite fonction serverless qui stocke un classement
- `docs/` : notes de mise en place du classement (Supabase, Vercel)
