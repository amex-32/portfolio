Cyberpunk Shop DETAILS

JavaScriptNode.jsExpressMySQL
View the codeAll projects

Description

A vehicle shop set in a cyberpunk universe. The front end is plain HTML and JavaScript, the API runs on Node.js with Express, and the data lives in a MySQL database. Each vehicle comes in several colour variants, each with its own visuals.

The API serves the catalogue (vehicle list and detail), order creation, and sign-up / login. The SQL schema, migrations and seed data are versioned alongside the code.

Technologies

JavaScriptNode.jsExpressMySQLHTML/CSS

Features

  • Catalogue and detail page for each vehicle
  • Colour variants with their own visuals
  • Cart and order creation
  • User sign-up and login
  • SQL migrations and seed data included
  • Fallback visual when an image is missing
