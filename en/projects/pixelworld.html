PixelWorld DETAILS

Live demo View the codeAll projects

Free hosting: the first load can take a minute.

Description

A collaborative web app inspired by r/place: several players place pixels on the same 1000 × 1000 canvas. The Node.js server keeps the grid state and broadcasts it to players over WebSocket with Socket.IO, and rendering happens in a Canvas.

The project was framed by a specification and a written architecture decision record (ADR): no database, the grid is kept in memory and saved to disk.

Technologies

Node.jsExpressSocket.IOCanvasJavaScript

Features

  • Shared 1000 × 1000 pixel canvas
  • Real-time updates over WebSocket, single or batched
  • Camera zoom and pan
  • Player nicknames and scores
  • Moderation: banning a player
  • Grid and scores saved to disk
  • Specification and ADR in the docs folder
