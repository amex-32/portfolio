Spotify API DETAILS

View the code
APISchool projectGo

Description

A web app in Go that consumes the Spotify API. The home page shows two artists side by side; each leads to a dedicated page, albums for Damso and tracks for Laylow.

Authentication uses Spotify's client credentials flow, and the interface has a "Liquid Glass" look with an animated background.

Technologies

GoSpotify Web APIOAuth (client credentials)HTML/CSS

Features

  • Home page with two clickable artists
  • Damso albums page
  • Laylow tracks page
  • Spotify authentication with client credentials
  • "Liquid Glass" interface with animated background
  • Layout adapted to small screens
