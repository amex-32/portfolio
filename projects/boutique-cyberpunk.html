Boutique Cyberpunk DÉTAILS

Voir le code
WebProjet de formationJavaScript

Description

Site de vente de véhicules dans un univers cyberpunk. Le front est en HTML et JavaScript, l'API en Node.js avec Express, et les données sont dans une base MySQL. Chaque véhicule existe en plusieurs variantes de couleur, avec ses propres visuels.

L'API expose le catalogue (liste et fiche d'un véhicule), la création de commandes ainsi que l'inscription et la connexion. Le schéma SQL, les migrations et les jeux de données sont versionnés avec le code.

Technologies

JavaScriptNode.jsExpressMySQLHTML/CSS

Fonctionnalités

  • Catalogue et fiche détaillée de chaque véhicule
  • Variantes de couleur avec leurs visuels
  • Panier et création de commandes
  • Inscription et connexion des utilisateurs
  • Migrations SQL et jeux de données fournis
  • Visuel de repli quand une image est introuvable
