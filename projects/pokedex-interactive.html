Description

Application web écrite en Go qui consomme l'API Tyradex pour afficher les Pokémon. Le serveur récupère les données, les range dans des structures Go dédiées, puis rend des pages HTML à partir de templates.

Le projet met l'accent sur le lien entre le backend Go et l'interface : routes, mapping des données de l'API et rendu côté serveur, sans framework JavaScript.

Technologies

Gonet/httphtml/templateTyradex APIHTML/CSS

Fonctionnalités

  • Accueil avec un Pokémon tiré au hasard
  • Collection avec recherche par nom
  • Filtres par type, génération (1 à 9) et formes spéciales
  • Fiche détaillée : stats, talents, résistances, évolutions, sprites
  • Favoris ajoutés ou retirés depuis les fiches
  • Pages rendues côté serveur avec html/template
